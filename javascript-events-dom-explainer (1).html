Phase 1: What is the DOM?

🌳 Software Fundamental: Document Structure & Object Model
DOM = Document Object Model

The DOM is how JavaScript "sees" the HTML page. It's a live, tree-like representation of all HTML elements that JavaScript can access and modify.

📋 Example 1: HTML vs DOM

Your HTML code:

<html> <head> <title>My Page</title> </head> <body> <h1>Welcome</h1> <p>Hello World</p> </body> </html>

Is converted into a DOM tree that looks like:

html ├── head │ └── title │ └── "My Page" └── body ├── h1 │ └── "Welcome" └── p └── "Hello World"
🔗 Example 2: Why the DOM Matters

With the DOM, JavaScript can:

  • ✓ Read HTML elements and their content
  • ✓ Modify text, colors, sizes of elements
  • ✓ Add or remove elements from the page
  • ✓ Respond to user actions (clicks, typing, etc.)
  • ✓ Show/hide elements
  • ✓ Validate form data
✅ KEY CONCEPT:

JavaScript doesn't directly change HTML files. Instead, it modifies the DOM (which is in memory), and the browser updates what the user sees.

Phase 2: Selecting DOM Elements

🎯 Software Fundamental: Element Selection & Querying
Before you can modify an element, you must SELECT it.

JavaScript provides multiple methods to find and select elements from the page.

🎯 Example 1: Different Selection Methods
// By ID (unique identifier) const header = document.getElementById("main-heading"); // By class name (can have multiple) const buttons = document.getElementsByClassName("button"); // By tag name const paragraphs = document.getElementsByTagName("p"); // Modern way - CSS selectors (most flexible) const element = document.querySelector(".my-class"); // First match const allElements = document.querySelectorAll("div p"); // All matches
👉 INTERACTIVE DEMO: Element Selection

📍 Example 2: CSS Selectors (Most Powerful)
// Select by ID document.querySelector("#my-id"); // Select by class document.querySelector(".my-class"); // Select by tag document.querySelector("button"); // Combinations document.querySelector("div.container"); document.querySelector("button.primary"); document.querySelector("header nav a");
✅ BEST PRACTICE:

Use querySelector/querySelectorAll - they work with CSS selectors and are the modern standard.

Change text, HTML, styles, attributes, and more.

📝 Example 1: Changing Text Content

Phase 4: Understanding Events

⚡ Software Fundamental: Event-Driven Programming
Events are things that happen on the page that you can RESPOND TO.

User clicks a button, types in a text box, hovers over an element - these are all events!

📋 Example 1: Common Events
Event When It Happens Example
click User clicks on element Button, link clicked
input User types in text box Real-time search
change User changes a value Dropdown, checkbox
submit Form is submitted Login form
mouseover Mouse enters element Hover effects
keydown User presses key Keyboard shortcuts
🔄 Example 2: Event Flow
1. Event Happens
User clicks on a button
↓
2. Browser Detects
Browser registers the click
↓
3. Your Code Runs
JavaScript handler function executes
↓
4. Page Updates
Page content changes based on your code

Phase 5: Handling Events

🎮 Software Fundamental: Interactivity & User Response
To respond to events, you create EVENT HANDLERS.

These are functions that run when a specific event occurs.

🔌 Example 1: Adding Event Listeners
// Get the element const button = document.querySelector("button"); // Method 1: HTML attribute (older) <button onclick="myFunction()">Click Me</button> // Method 2: addEventListener (modern, recommended) button.addEventListener("click", function() { console.log("Button was clicked!"); }); // Or using arrow function button.addEventListener("click", () => { console.log("Button was clicked!"); });
👉 TRY IT: Handle Click Events
Click counter will appear here
⌨️ Example 2: Handling Input Events
const input = document.querySelector("input"); // Respond to user typing input.addEventListener("input", function(event) { console.log("User typed:", event.target.value); });
👉 TRY IT: Input Events
What you type will appear here
📝 Example 3: Form Submission
const form = document.querySelector("form"); form.addEventListener("submit", function(event) { event.preventDefault(); // Stop default submission const name = document.querySelector("input[name='name']").value; console.log("Form submitted with name:", name); });
